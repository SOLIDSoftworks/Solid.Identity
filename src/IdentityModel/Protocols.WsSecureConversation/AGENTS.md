# WS-SecureConversation protocol model and serialization

All features added to this project must comply with the [WS-SecureConversation 1.3 specification](https://docs.oasis-open.org/ws-sx/ws-secureconversation/200512/ws-secureconversation-1.3-os.html). Consult the applicable requirements before implementing or reviewing a feature, and verify that its behavior and XML serialization conform to the specification.
