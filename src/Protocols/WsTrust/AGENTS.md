# WS-Trust service implementation

All features added to this project must comply with the applicable WS-Trust specification. Before making any change, consult the relevant requirements in all applicable versions:

- [WS-Trust February 2005](https://specs.xmlsoap.org/ws/2005/02/trust/WS-Trust.pdf)
- [WS-Trust 1.3 (December 2005)](https://docs.oasis-open.org/ws-sx/ws-trust/200512/ws-trust-1.3-os.html)
- [WS-Trust 1.4 (February 2008)](https://docs.oasis-open.org/ws-sx/ws-trust/v1.4/os/ws-trust-1.4-spec-os.html)

Identify which version(s) and operations the change affects. Check the applicable request and response semantics, required elements, faults, security requirements, and version-specific differences before implementing or reviewing it. Ensure the behavior follows the specifications, and cover affected versions in tests. If a requirement is intentionally unsupported, document the limitation rather than silently treating it as supported.
