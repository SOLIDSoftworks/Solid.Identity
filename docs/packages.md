# Packages

Install packages from NuGet using `dotnet add package <package-name>`. The guides cover the main entry points; the package links below lead to their NuGet pages.

## HTTP

- [Solid.Http](https://www.nuget.org/packages/Solid.Http): convenience package for the core client and JSON support. [HTTP guide](http.md).
- [Solid.Http.Core](https://www.nuget.org/packages/Solid.Http.Core): fluent HTTP client infrastructure.
- [Solid.Http.Json](https://www.nuget.org/packages/Solid.Http.Json): JSON serialization.
- [Solid.Http.Xml](https://www.nuget.org/packages/Solid.Http.Xml): XML serialization.
- [Solid.Http.Zip](https://www.nuget.org/packages/Solid.Http.Zip): ZIP response handling.
