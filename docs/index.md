# Solid.Identity

Solid.Identity is a collection of .NET packages for HTTP clients, identity protocols, web API testing, SOAP services, and related infrastructure.

## Get started

Install the package that matches your use case with the .NET CLI. For example, to make fluent HTTP requests with JSON support:

```console
dotnet add package Solid.Http
```

Then [set up an HTTP client](http.md), or choose a different package from the [package catalog](packages.md).

## Guides

- [HTTP client](http.md): configure the fluent client and serialize JSON, XML, or ZIP responses.
- [SAML 2.0](saml2p.md): integrate a service provider or identity provider with ASP.NET Core.
- [Testing web APIs](testing.md): host an API and make assertions against its responses.
- [SOAP services](soap.md): host a SOAP endpoint in ASP.NET Core.

The [repository](https://github.com/SOLIDSoftworks/Solid.Identity) contains the source code and more detailed package README files.
